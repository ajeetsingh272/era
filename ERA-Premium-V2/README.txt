ERA Interior website
====================
Run: double-click index.html (opens in browser). Internet needed only for Google Fonts.

Files
  index.html      page structure
  css/style.css   design and animations
  js/script.js    products, text content, slider, routing
  images/         all photos

Edit contact details: js/script.js -> search CFG (top of file) and change phone, email, address, website.
Change photos: replace files in images/ with your own using the SAME file name
  (e.g. ipe_h.jpg = IPE banner, ipe_s.jpg = colour samples, about.jpg = tall hero photo, cov.jpg = wide cover).
Edit product text: js/script.js -> const P (names, features), const X (details), const M (material guide).
Upload to hosting: upload the whole folder as it is.

Material swatches: images/<product>_t1.jpg, _t2.jpg ... are the sample swatches shown in "Types & quality" on each product page.
Replace them with real photos of your own stock using the same file names. Text for each type is in js/script.js -> const TY.
